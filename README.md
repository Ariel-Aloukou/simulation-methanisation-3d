# BioFlow 3D — simulation pédagogique de la méthanisation

## Lancer
```bash
npm install
npm run dev
```

Puis ouvrir l'adresse affichée par Vite.

## Objectif
Cette interface sert à comprendre visuellement le processus :
déchets → tri → prétraitement → méthaniseur → hydrolyse → acidogenèse → acétogenèse → méthanogenèse → biogaz/digestat → valorisation.

Ce n'est pas un modèle industriel ni un simulateur physico-chimique. Les animations sont pédagogiques.
